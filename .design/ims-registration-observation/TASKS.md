# IMS 注册观测任务清单

来源：[设计说明](DESIGN_BRIEF.md)、[开发计划](DEVELOPMENT_PLAN.md)。日期：2026-11-11。

本清单未开始实施。用户已确认中心可访问的多来源及站点／网络关联，远端 Agent 后续扩展。

## 来源与最小观测闭环

- [ ] **核验实际来源能力**：确认 S-CSCF／HSS 版本、表关系、Contact 状态、时区、持久化模式、读权限和身份映射，冻结 API 与计数口径；无法核验时列明可实现与现场未知项。_新建：来源适配契约；复用：现有 UE 来源状态规则。_
- [ ] **打通单来源只读观测**：受限配置、生命周期受控连接池、固定查询和最小来源状态条／身份表形成可操作闭环，无配置与 schema 不支持均能解释。_新建：IMS 读取器、模型与页面；复用：Go auth、OperationsPageFrame、MetricStrip、OperationFeedback。依赖：来源资格。_
- [ ] **扩展多来源和明确分母**：独立显示每源状态，测试共享 Contact、多 IMPU 和重复来源；失败时只显示已观测数量，不伪造全范围总量。_修改：IMS API、来源条和摘要；复用：端点限流。依赖：单来源闭环。_

## 身份、范围与导航闭环

- [ ] **补充可验证身份并开放证据抽屉**：HSS 批量、可选、无 N+1；缺失／歧义映射保持未知，抽屉展示绑定证据和时间。_新建：HSS 只读适配与 IMS 抽屉；复用：共享 Dialog／详情交互。依赖：多来源模型。_
- [ ] **接入站点／网络筛选**：按源资源 UUID 调用既有范围解析，验证空交集、来源归属冲突和共享 S-CSCF；文案明确范围指来源组织归属。_复用：ResolveGroupScope；修改：分组跳转、IMS 查询和筛选。依赖：多来源模型。_
- [ ] **实现可恢复分页与刷新**：绑定上下文的游标、URL 筛选、来源切换请求取消、单一手动刷新和可选轮询，返回恢复原列表。_复用：useRead、URL 状态、returnTo；新建：IMS 查询模型。依赖：范围与 API 契约。_
- [ ] **接入运维总览摘要**：用新字段展示有效绑定／公开身份计数，保留旧 IMS 字段兼容和 EPC/5GC 独立读取。_修改：运维摘要与 UE 视图切换；复用：共享工作台导航。依赖：多来源计数。_

## 验证与交付

- [ ] **完成真实 SQL 隔离集成**：验收拥有的临时 MySQL，覆盖 SQL、时区、到期、状态、权限和超时；不使用生产库 fixture。_新建：有界集成测试；复用：现有自有进程验收模式。依赖：适配器。_
- [ ] **完成界面交互和可访问性核查**：中英文、明暗主题、1920／1366／390、实际 80%／200% 缩放、键盘焦点和不同来源状态。_修改：既有样式 token 下的 IMS 组件；复用：共享反馈和焦点机制。依赖：核心 UI。_
- [ ] **完成设计审查**：按设计说明核对单位、信息层级、证据时间、响应式布局和可访问名称，记录并修复偏差。_复用：design-review 工作流；修改：发现偏差的 IMS 组件。依赖：浏览器核查。_
- [ ] **完成工程交付**：Go／前端完整检查、契约门禁、文档、可回退构建与分离提交；严格区分开发完成和真实环境可用。_修改：相关 contract、当前系统文档和必要的配对规则文件。依赖：全部开发验收。_
- [ ] **记录现场验收**：真实来源与正常 UE 注册／续期／注销核验，记录数据库与运行时一致性及多来源覆盖；未具备条件则保持 NOT_RUN。_复用：部署者操作边界；新建：脱敏现场证据。依赖：部署及来源就绪，不阻断可独立完成的隔离开发。_

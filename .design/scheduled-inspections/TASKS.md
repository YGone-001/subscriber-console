# 定时巡检工作台实施任务

来源：[DESIGN_BRIEF.md](DESIGN_BRIEF.md)、[IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。日期：2026-11-19。所有实施项待开发；本清单不是验收完成声明。

## 切片 1：一个计划的手动巡检闭环

- [ ] **只读范围与五类证据适配**：新增 inspections 服务与正向字段投影，复用 operationsview 范围、NF Health 新鲜度、配置及漂移、NF 告警和 Agent 语义；形成可供预览与手动运行共用的有界结果。新增独立来源失败、空范围、缺失／过期／未来时间、漂移 pending、未监测和无基线 fixture；确认对来源零写入。_复用：现有 domain service／repository；新增：批量只读适配与判定版本。依赖：无。_
- [ ] **创建暂停计划并预览**：实现 preview／创建／详情 API 和 `/inspections/new`、计划详情；显示范围、检查集合、年龄阈值及日历预览，保存暂停计划后可重新打开。_复用：OperationsPageFrame、Field、StatePanel、UnsavedChangesGuard、mutation/read client；新增：计划编辑与预览组件。依赖：只读适配。_
- [ ] **立即巡检与固定执行页**：实现幂等 POST、持久化 run、有限执行器及运行详情／items，展示执行状态、问题和完整性；刷新及重开页仍读取相同已保存内容。_复用：MetricStrip、CursorPagination、OperationFeedback；新增：执行摘要与证据详情。依赖：计划创建。_
- [ ] **验证首个可用闭环**：隔离 Mongo 验证主体／幂等／CAS 和真实存储行为；浏览器走“预览—保存—立即巡检—查看—刷新”，同时验证 viewer 拒绝、旧数据不能通过、源更新不改旧报告。_复用：项目独占 fixture／Playwright 模式；新增：有用户可见断言的集成验收。依赖：固定执行页。_

## 切片 2：目录、维护与范围入口

- [ ] **巡检目录与执行历史**：实现 `/inspections` 计划／执行切换、全结果摘要、服务器筛选与游标；计划详情展示历史。_复用：ViewSwitch、CursorPagination、StatePanel；新增：计划与执行目录。依赖：切片 1。_
- [ ] **计划编辑、启停与归档**：实现 revision 校验、Fresh Actor 和草稿保留；默认暂停，归档要求无活动 run。执行中的计划快照保持不变。_复用：Dialog、UnsavedChangesGuard、OperationFeedback；修改：计划编辑器。依赖：目录。_
- [ ] **分组上下文和既有证据跳转**：运维导航增加巡检入口，分组页带范围创建；详情保留 returnTo，引用进入原资源／告警／配置／Agent 页面。_复用：OperationsNav、安全 return-to、现有分组筛选；修改：导航／路由／分组页及其契约。依赖：目录与维护。_

## 切片 3：自动调度与异常恢复

- [ ] **启用真实日历计划**：接入 interval／daily／weekly、IANA 时区、后五次预览、调度器生命周期／meta；启用计划后定时产生与手动一致的 run。_复用：进程内任务生命周期与可注入时钟模式；新增：时间计算与调度状态面板。依赖：切片 2。_
- [ ] **并发、漏跑与权限变化闭环**：完成 occurrenceKey、有限队列、两 worker、每计划 single-flight、原子租约与 fencing、调度日志投影、授权主体重验、暂停／改计划竞争和 missed／skipped／interrupted 展示。_复用：Mongo CAS／现有用户权威；修改：执行器与状态组件。依赖：自动调度。_
- [ ] **以故障注入验收调度**：验证持久化前后崩溃、投影失败、旧 worker 晚到、响应丢失重试、积压、停机、回拨、DST 和失权；以固定时钟及实际 Mongo 保证结果可复现。_复用：隔离服务与 fixture harness；新增：恢复和时间边界断言。依赖：异常恢复。_

## 切片 4：固定报告、对比与容量

- [ ] **同一 run 的 CSV／JSON 导出**：实现导出 API 与按钮，列出当次范围、时间、判定依据和缺口；敏感字段白名单、公式注入及体积限制。_复用：现有 CSV 防护与 getBlob 模式；新增：固定报告序列化和下载状态。依赖：切片 1。_
- [ ] **兼容条目上次对比**：对同计划兼容检查版本／身份生成新增问题、本次未再检出、范围新增／移出和无法比较，不改源告警状态。_复用：现有身份与历史目录；新增：对比投影／展示。依赖：目录、固定报告。_
- [ ] **保留、索引和容量准入**：实现 dry-run 默认的 inspections-init、终态 TTL、运行与计划边界、容量 meta 和满额拒绝；运行中记录不被 TTL 清除。_复用：既有索引 CLI 习惯；新增：本模块索引与有界容量管理。依赖：调度记录与导出。_

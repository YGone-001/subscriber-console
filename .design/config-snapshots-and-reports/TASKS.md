# Build Tasks: 配置观测快照与运维报表

## 交付 A：配置快照

- [ ] **CS-01：可登记来源的只读目录与页面。** 新增静态 manifest 的有界校验、meta/sources 读取与 `/config-snapshots`；页面展示来源、明确资源绑定、支持模式和“尚未采集”。冻结请求/响应及初始预算，不读取任意浏览器路径、不在 GET 中写 DB。复用 PageHeader、MetricStrip、CursorPagination、StatePanel、既有 token/locale/认证；新增 ConfigSourcesPage 与来源模型。完成标准：未配置、合法、非法路径、缺失资源、未关联、远程不支持均可区分；超限与 viewer 权限可验证。依赖：无。

- [ ] **CS-02：受控读取与真实采集结果。** 为登记来源提供 capture 操作及最近结果，先支持 metadata-only；记录来源 generation、时间、读取结果和幂等请求 ID。验证常规文件、目录边界、符号链接、文件替换、读取中变化、超限与取消。复用 Fresh Actor、core.configure、best-effort 审计、Dialog/OperationFeedback；新增配置采集服务、Ops 来源/观测记录与详情状态。完成标准：真实成功与权限失败可展示，viewer 403、失效主体拒绝、失败不冒充成功，读取源文件始终只读。依赖：CS-01。

- [ ] **CS-03：安全 YAML/JSON 投影可查看。** 在来源详情展示批准字段的规范化脱敏投影；未知格式、未知结构与不安全解析转 metadata-only。加入内部 HMAC 指纹及策略/密钥版本，不存原文、不暴露原文摘要。复用已有详情布局、SectionHeader、StatePanel；新增投影策略、内容可见范围与 ConfigEvidenceStatus。完成标准：嵌套密钥、注释、未知字段、重复键、带凭据 URI 等夹具不会泄漏到 DB/API/日志/页面，metadata-only 不伪装空配置。依赖：CS-02。

- [ ] **CS-04：版本历史与观测记录。** 同内容只追加观测，不重复内容版本；新内容生成不可变 UUID 版本，详情展示历史并支持游标与直接选择。复用 CursorPagination、DataTableState、returnTo/URL 状态；新增不可变快照仓储与版本列表。完成标准：重复请求、两个并发采集、A→B→A、失败重试、进程重启后查询都保留正确历史；旧内容不被覆盖。依赖：CS-03。

- [ ] **CS-05：任意两个兼容版本的差异。** 提供同来源差异接口与版本选择 UI；实现规范化投影的有界序列 diff，桌面并排、窄屏统一视图。复用 ViewSwitch、Field、状态面板和等宽 token；新增 ConfigVersionDiff。完成标准：插行/删行/重复行/空文件/有序数组语义正确，跨来源拒绝，秘密不出现，超时/过长/metadata-only/策略不兼容均给明确原因。依赖：CS-04。

- [ ] **CS-06：设置基线与有依据的漂移提示。** 设置/替换/清除基线使用 expectedRevision CAS；来源列表显示最近快照相对基线的比较及其时间，不宣称配置健康。复用 Dialog、Field、OperationFeedback、MetricStrip；新增基线服务与状态维度。完成标准：首次不自动设基线、并发 409、已退役资源拒绝新变更、换 generation/策略/密钥不产生伪漂移，隐藏内容变化不称具体秘密变化。依赖：CS-05。

- [ ] **CS-07：固定周期采集及运行可见性。** 在服务端允许清单中声明固定间隔，默认关闭；与手动采集共用实现，详情展示下一计划、最近结果和失败原因。复用 Go 生命周期/退出机制、观测记录和 SectionHeader；新增专用调度 worker，不新增通用任务菜单或命令。完成标准：每来源互斥、全局并发有界、重启不补跑无界任务、慢文件不拖垮其他来源、停止进程后没有遗留 worker。依赖：CS-06。

- [ ] **CS-08：可持续的保留与容量限制。** 实现观测保留、内容版本清理、保护当前基线/最近成功引用和明确的容量拒绝；页面可见保留策略与容量失败。复用来源状态、worker 生命周期、StatePanel；新增专用保留策略和显式集合约束初始化说明。完成标准：基线设置与清理竞争不产生悬空引用，受保护内容不被 TTL 删除，来源移除仍能读历史，达到硬上限不会伪成功。依赖：CS-06；与 CS-07 的交互需集成验证。

- [ ] **CS-09：配置功能的真实只读交付。** 在 Linux 上使用批准来源验证采集、脱敏、基线与差异，补全故障矩阵和桌面/移动操作；同步最终文档、路由契约和唯一计数权威。复用 Go/React/架构门禁与当前部署流程；修改注册/导航/read-mutation 契约，新增本功能架构和运维说明。完成标准：单元、集成、race、vet、build、浏览器及门禁通过；合成密钥无泄漏；观测文件无写入；提供可核对的最终 SHA 证据。真实网元配置不能为测试被修改或重启。依赖：CS-07、CS-08。

交付 A 的发布判据：来源、采集、历史、差异、基线、失败态、容量和权限形成完整链路；元数据模式仍有明确价值。仅完成页面或夹具演示不算实际只读接入验收。

## 交付 B：运维报表

- [ ] **RP-01：按时间窗生成告警摘要。** 新增统一查询规范和 `/ops-reports`，提供新增/确认/关闭实例、有效处理用时与单列的当前待办。复用 NF Alert 权威模型、PageHeader、Field、MetricStrip、StatePanel；新增 opsreports 查询服务和 OperationsReportPage。完成标准：半开窗口、跨窗口实例、非法/缺失时间、关闭原因和有效样本分母都准确；triggerCount 不充当窗口次数，当前队列不充当历史状态。依赖：CS-09（产品交付顺序）；技术上不依赖配置正文。

- [ ] **RP-02：监测样本摘要与覆盖。** 添加目标/指标的样本数、首末时间、last/min/max 和适用 gauge 均值，提供分页明细及等价数据表。复用 NF Health 注册表和历史样本、ChartDataTable/chartPrimitives/Recharts；新增 ReportCoverage 与指标聚合投影。完成标准：保留期不足、空样本、断档、counter、缺失值、不同目标不可混算；不生成历史 SLA、成功率或虚构采样覆盖率。依赖：RP-01。

- [ ] **RP-03：配置摘要与 Agent 当前状态。** 报表读取配置观测元数据及 Agent 最新记录，分区说明时间与归属范围；支持资源筛选的分区才应用资源条件。复用 A 的来源/观测仓储与现有 Agent 投影；新增报表分区适配器和 ReportSection。完成标准：不触发采集、不读取配置正文、不把 latest Agent 当历史；某分区失败不伪造零值，无法应用筛选的分区不混入全平台数。依赖：RP-02、CS-09。

- [ ] **RP-04：一致口径的 CSV 导出。** 告警、指标、配置分区共享查询规范与字段解释；导出时间、范围、来源与 null 语义可读。复用认证、读取权限、反馈组件；新增 CSV writer 和导出控件，不新增报表存储/任务系统。完成标准：公式注入、Unicode、引号、换行、10k 行/10 MiB 预检、取消和来源失败均覆盖；没有静默截断和伪空报表。独立请求的生成时间明确可见。依赖：RP-03。

- [ ] **RP-05：报表性能、交互与真实数据验收。** 使用代表性记录检查查询执行计划、全量摘要与分页明细，验证筛选并发、浏览器返回、移动布局、键盘和图表数据表；完成最终契约与文档。复用现有门禁、分页/URL/焦点机制；修改最终注册与文档，仅按实际缺口补领域组件。完成标准：高于页容量的数据统计不缩水、读请求零业务写入、超预算明确错误、部分来源失败可解释，最终 Linux/React/浏览器验收通过。依赖：RP-04。

交付 B 的发布判据：每个数字都能追溯时间字段、分区来源、实际筛选和有效样本；无证据的可用率、预测和历史归属不出现。
